2. Using the app

  • Use Roll to generate a new anime-style prompt, then copy or share the text.
  • Pick a default output model in Settings if you use a specific AI tool.
  • Refresh the tag library from Settings if new tags were published.
  • Turn on the SFW safety filter to reduce mature tags.

3. Pro & ads

  • Pro (rollcall_pro) is a one-time purchase that removes ads.
  • Use Restore purchase in Settings if you reinstall or change devices.
  • Ad consent can be managed via Google UMP when shown, or Android ad settings.

4. Data deletion

Android Settings → Apps → Anime Prompt Builder → Storage → Clear data, or uninstall.
